Emberkeeper is a complete arcade survival game: guide the last lantern keeper through a dark meadow, gather embers to build your combo, flare away the shadow wisps that hunt you, and survive ten waves until dawn breaks.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: the game is plain static files under `game/`.
